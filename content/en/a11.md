## 🏢 The situation

The meeting where the project's fate is decided. Marina:

> "Eighty percent of emails go out without edits. Igor still opens every one. That is not review any more, that is ritual. Let's send automatically."

Igor does not argue, but he does not agree either: "While I press the button, the emails are on me. If a robot sends them, they are still on me — except now I haven't looked."

Olya from legal adds: "We are regulated fintech. For any email that went out I need to show: who authorized it, when, and on what basis. A year from now, during an audit."

All three are right. The task is not to pick a side but to design so that automation grows while accountability stays traceable.

## 🎯 Your task

1. Decide what goes out automatically and what needs approval — by cost of a mistake, not by a percentage.
2. Make approval fast: nobody performs a hundred-click ritual for long.
3. Build an audit trail that survives an inspection a year later.

## 📚 Theory

### Gates do not go on everything

From A1 we remember the autonomy ladder. Now it applies not to the agent as a whole but **to each action type separately**:

| Action | Cost of a mistake | Mode |
| --- | --- | --- |
| A note in the CRM | A junk line a manager sees | Auto |
| Email to a new lead | Awkward but recoverable | Auto at high confidence |
| Email to an existing customer | May disturb an open deal | Approval |
| Reply to a pricing objection | A promise you must honour | Always human |
| Anything after a complaint | Escalation | Always human |

The point: **autonomy is granted per action type, not wholesale**. That way the system grows gradually instead of jumping from "we check everything" to "we check nothing".

### Approval must take seconds

A gate that requires reading the whole email is not control, it is a tax. A good approval interface shows:

- **what will change** (recipient, subject),
- **on what basis** (the hook and its source),
- **what looks off** — the results of automatic checks,
- and allows **batch approval** for everything that raises no questions.

The practical rule: if approving twenty emails takes more than five minutes, people start approving without looking. Then the gate becomes fiction — the worst possible outcome, because responsibility has formally left the system while nobody actually checked.

### The audit trail: what must survive a year

For an audit, Olya needs immutable records showing, for every email sent:

| Field | Why |
| --- | --- |
| What was sent (full text) | The subject of the dispute |
| Who authorized it (a human, or the auto-send rule) | Accountability |
| Which facts and which prompt version | Reproducibility of the decision |
| Automatic check results | What the system knew at send time |
| Decision time and send time | Whether cancelling was possible |

The key word is **immutable**: an append-only log that cannot be edited retroactively. Otherwise the trail carries no evidentiary weight.

## 💻 Practice

```python
import os, json, hashlib, datetime as dt, sqlite3

audit = sqlite3.connect("audit.db")
audit.execute("""CREATE TABLE IF NOT EXISTS trail (
    id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL, action TEXT NOT NULL,
    lead_id TEXT, payload TEXT NOT NULL, decided_by TEXT NOT NULL,
    basis TEXT, prompt_version TEXT, checks TEXT, prev_hash TEXT, row_hash TEXT)""")

def log_event(action, lead_id, payload, decided_by, basis=None,
              prompt_version=None, checks=None):
    """Append-only with a hash chain: a row cannot be swapped retroactively unnoticed."""
    prev = audit.execute("SELECT row_hash FROM trail ORDER BY id DESC LIMIT 1").fetchone()
    prev_hash = prev[0] if prev else ""
    ts = dt.datetime.now(dt.timezone.utc).isoformat()
    body = json.dumps({"ts": ts, "action": action, "lead_id": lead_id, "payload": payload,
                       "decided_by": decided_by, "basis": basis,
                       "prompt_version": prompt_version, "checks": checks},
                      sort_keys=True)
    row_hash = hashlib.sha256((prev_hash + body).encode()).hexdigest()
    audit.execute("INSERT INTO trail (ts, action, lead_id, payload, decided_by, basis, "
                  "prompt_version, checks, prev_hash, row_hash) VALUES (?,?,?,?,?,?,?,?,?,?)",
                  (ts, action, lead_id, json.dumps(payload), decided_by,
                   json.dumps(basis) if basis else None,
                   prompt_version, json.dumps(checks) if checks else None,
                   prev_hash, row_hash))
    audit.commit()
    return row_hash


def verify_trail():
    """Integrity check: any retroactive edit breaks the chain."""
    prev_hash = ""
    for row in audit.execute("SELECT ts, action, lead_id, payload, decided_by, basis, "
                             "prompt_version, checks, prev_hash, row_hash FROM trail ORDER BY id"):
        (ts, action, lead_id, payload, decided_by, basis, pv, checks, stored_prev, stored) = row
        body = json.dumps({"ts": ts, "action": action, "lead_id": lead_id,
                           "payload": json.loads(payload), "decided_by": decided_by,
                           "basis": json.loads(basis) if basis else None,
                           "prompt_version": pv,
                           "checks": json.loads(checks) if checks else None},
                          sort_keys=True)
        if stored_prev != prev_hash or hashlib.sha256((prev_hash + body).encode()).hexdigest() != stored:
            return False, ts
        prev_hash = stored
    return True, None


# --- Policy: the mode depends on action type and confidence ---
HOLD_MINUTES = 15

def decide_mode(lead, draft, checks):
    if lead.get("has_open_deal"):
        return "approve", "the lead has an open deal"
    if checks.get("mentions_objection_price"):
        return "approve", "pricing is involved — human only"
    if lead.get("complaint_history"):
        return "approve", "there is a complaint in the history"
    if checks["confidence"] < 0.75 or checks["problems"]:
        return "approve", "low confidence or automatic checks flagged something"
    return "hold", f"auto-send in {HOLD_MINUTES} minutes, cancellable"


def enqueue(lead, draft, ctx, checks):
    mode, why = decide_mode(lead, draft, checks)
    send_at = (dt.datetime.now(dt.timezone.utc) +
               dt.timedelta(minutes=HOLD_MINUTES)).isoformat() if mode == "hold" else None
    log_event("queued", lead["id"], {"subject": draft["subject"], "body": draft["body"],
                                     "mode": mode, "send_at": send_at, "why": why},
              decided_by="agent:outreach", basis=ctx.get("sources"),
              prompt_version=PROMPT_VERSION, checks=checks)
    return {"mode": mode, "why": why, "send_at": send_at}


def approve(item_id, user_email):
    """An explicit human decision is its own record in the trail."""
    log_event("approved", item_id, {"item": item_id}, decided_by=f"human:{user_email}")
    send(item_id)
    log_event("sent", item_id, {"item": item_id}, decided_by=f"human:{user_email}")


def auto_send_due():

    for item in due_items():
        if item["cancelled"]:
            log_event("cancelled", item["lead_id"], {"item": item["id"]},
                      decided_by=f"human:{item['cancelled_by']}")
            continue
        send(item["id"])
        log_event("sent", item["lead_id"], {"item": item["id"]},
                  decided_by="rule:auto_send_after_hold")   # shows no human looked
```

What matters here:

1. **The mode is chosen per action type**, not from an overall quality percentage. Open deals and pricing conversations always route through a human.
2. **The cancel window** settles the Marina–Igor argument: nearly the speed of auto-send, but with a brake.
3. **`decided_by` is always populated.** A year later you can see whether a human or a rule sent that email. That is exactly what Olya needs.
4. **A hash chain.** A record cannot be edited retroactively unnoticed — `verify_trail()` shows where the chain broke.
5. **Cancellation is an event too.** The absence of a record proves nothing; an explicit record does.

## 📌 Remember

- Autonomy is granted per action type, not wholesale — that is what lets it grow gradually.
- Delayed send with a cancel window is usually the compromise the business actually needs.
- Approval must take seconds and support batching, or it degenerates into fiction.
- A gate people click through without looking is worse than no gate: responsibility moved, review did not happen.
- The audit trail keeps the text, the basis, the prompt version, the check results and who authorized it.
- The log must be append-only with verifiable integrity, or it carries no evidentiary weight.
