## 🏢 Ситуация

Совещание, на котором решается судьба проекта. Марина:

> «Восемьдесят процентов писем уходят без правок. Игорь всё равно открывает каждое. Это уже не проверка, это ритуал. Давайте отправлять автоматически.»

Игорь не спорит, но и не соглашается: «Пока я нажимаю кнопку, отвечаю за письма я. Если отправляет робот — отвечаю всё равно я, но уже не глядя».

Оля из юридического добавляет: «У нас регулируемый финтех. Мне нужно, чтобы по любому отправленному письму я могла показать: кто санкционировал, когда, на основании чего. Через год, на проверке».

Все трое правы. Задача — не выбрать между ними, а спроектировать так, чтобы автоматизация росла, а ответственность оставалась прослеживаемой.

## 🎯 Ваша задача

1. Выбрать, что уходит автоматически, а что требует подтверждения — по цене ошибки, а не по проценту.
2. Сделать подтверждение быстрым: ритуал из ста кликов никто выполнять не будет.
3. Построить аудит-трейл, который переживёт проверку через год.

## 📚 Теория

### Гейт ставят не на всё подряд

Из A1 мы помним лестницу автономии. Теперь она применяется не ко всему агенту, а **к каждому типу действия отдельно**:

| Действие | Цена ошибки | Режим |
| --- | --- | --- |
| Заметка в CRM | Мусорная строка, видна менеджеру | Авто |
| Письмо новому лиду | Неловко, но исправимо | Авто при высокой уверенности |
| Письмо действующему клиенту | Может задеть открытую сделку | Подтверждение |
| Ответ на возражение о цене | Обещание, которое придётся исполнять | Всегда человек |
| Что угодно после жалобы | Эскалация | Всегда человек |

Смысл: **автономия выдаётся по типам действий, а не целиком**. Так система растёт постепенно, а не одним прыжком с «всё проверяем» на «ничего не проверяем».

### Подтверждение должно занимать секунды

Гейт, который требует прочитать письмо целиком, — это не контроль, а налог. Хороший интерфейс подтверждения показывает:

- **что изменится** (кому уходит, какая тема),
- **на основании чего** (зацепка и её источник),
- **что настораживает** — результаты автоматических проверок,
- и позволяет **одобрить пачкой** то, что не вызывает вопросов.

Практическое правило: если человек одобряет двадцать писем дольше пяти минут, он начнёт одобрять не глядя. Тогда гейт превращается в фикцию — худший из возможных исходов, потому что ответственность формально снята с системы, а фактически никто не проверял.

### Аудит-трейл: что должно остаться через год

Оле для проверки нужны неизменяемые записи, где по каждому отправленному письму видно:

| Поле | Зачем |
| --- | --- |
| Что отправлено (полный текст) | Предмет разбирательства |
| Кто санкционировал (человек или правило авто-отправки) | Ответственность |
| На основании каких фактов и версии промпта | Воспроизводимость решения |
| Результаты автопроверок | Что система знала на момент отправки |
| Время решения и время отправки | Была ли возможность отменить |

Ключевое слово — **неизменяемые**: append-only журнал, который нельзя отредактировать задним числом. Иначе трейл не имеет доказательной силы.

## 💻 Практика

```python
import os, json, hashlib, datetime as dt, sqlite3

audit = sqlite3.connect("audit.db")
audit.execute("""CREATE TABLE IF NOT EXISTS trail (
    id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL, action TEXT NOT NULL,
    lead_id TEXT, payload TEXT NOT NULL, decided_by TEXT NOT NULL,
    basis TEXT, prompt_version TEXT, checks TEXT, prev_hash TEXT, row_hash TEXT)""")

def log_event(action, lead_id, payload, decided_by, basis=None,
              prompt_version=None, checks=None):
    """Append-only с цепочкой хешей: задним числом строку не подменить незаметно."""
    prev = audit.execute("SELECT row_hash FROM trail ORDER BY id DESC LIMIT 1").fetchone()
    prev_hash = prev[0] if prev else ""
    ts = dt.datetime.now(dt.timezone.utc).isoformat()
    body = json.dumps({"ts": ts, "action": action, "lead_id": lead_id, "payload": payload,
                       "decided_by": decided_by, "basis": basis,
                       "prompt_version": prompt_version, "checks": checks},
                      ensure_ascii=False, sort_keys=True)
    row_hash = hashlib.sha256((prev_hash + body).encode()).hexdigest()
    audit.execute("INSERT INTO trail (ts, action, lead_id, payload, decided_by, basis, "
                  "prompt_version, checks, prev_hash, row_hash) VALUES (?,?,?,?,?,?,?,?,?,?)",
                  (ts, action, lead_id, json.dumps(payload, ensure_ascii=False), decided_by,
                   json.dumps(basis, ensure_ascii=False) if basis else None,
                   prompt_version, json.dumps(checks, ensure_ascii=False) if checks else None,
                   prev_hash, row_hash))
    audit.commit()
    return row_hash


def verify_trail():
    """Проверка целостности: любая правка задним числом ломает цепочку."""
    prev_hash = ""
    for row in audit.execute("SELECT ts, action, lead_id, payload, decided_by, basis, "
                             "prompt_version, checks, prev_hash, row_hash FROM trail ORDER BY id"):
        (ts, action, lead_id, payload, decided_by, basis, pv, checks, stored_prev, stored) = row
        body = json.dumps({"ts": ts, "action": action, "lead_id": lead_id,
                           "payload": json.loads(payload), "decided_by": decided_by,
                           "basis": json.loads(basis) if basis else None,
                           "prompt_version": pv,
                           "checks": json.loads(checks) if checks else None},
                          ensure_ascii=False, sort_keys=True)
        if stored_prev != prev_hash or hashlib.sha256((prev_hash + body).encode()).hexdigest() != stored:
            return False, ts
        prev_hash = stored
    return True, None


# --- Политика: режим зависит от типа действия и уверенности ---
HOLD_MINUTES = 15

def decide_mode(lead, draft, checks):
    if lead.get("has_open_deal"):
        return "approve", "у лида открытая сделка"
    if checks.get("mentions_objection_price"):
        return "approve", "затронута цена — только человек"
    if lead.get("complaint_history"):
        return "approve", "в истории есть жалоба"
    if checks["confidence"] < 0.75 or checks["problems"]:
        return "approve", "низкая уверенность или замечания автопроверок"
    return "hold", f"авто-отправка через {HOLD_MINUTES} минут, можно отменить"


def enqueue(lead, draft, ctx, checks):
    mode, why = decide_mode(lead, draft, checks)
    send_at = (dt.datetime.now(dt.timezone.utc) +
               dt.timedelta(minutes=HOLD_MINUTES)).isoformat() if mode == "hold" else None
    log_event("queued", lead["id"], {"subject": draft["subject"], "body": draft["body"],
                                     "mode": mode, "send_at": send_at, "why": why},
              decided_by="agent:outreach", basis=ctx.get("sources"),
              prompt_version=PROMPT_VERSION, checks=checks)
    return {"mode": mode, "why": why, "send_at": send_at}


def approve(item_id, user_email):
    """Явное решение человека — отдельная запись в трейле."""
    log_event("approved", item_id, {"item": item_id}, decided_by=f"human:{user_email}")
    send(item_id)
    log_event("sent", item_id, {"item": item_id}, decided_by=f"human:{user_email}")


def auto_send_due():
    """Окно отмены истекло — отправляем и фиксируем, что решение приняло правило."""
    for item in due_items():
        if item["cancelled"]:
            log_event("cancelled", item["lead_id"], {"item": item["id"]},
                      decided_by=f"human:{item['cancelled_by']}")
            continue
        send(item["id"])
        log_event("sent", item["lead_id"], {"item": item["id"]},
                  decided_by="rule:auto_send_after_hold")   # видно, что человек не смотрел
```

Что здесь важно:

1. **Режим выбирается по типу действия**, а не по общему проценту качества. Открытая сделка и разговор о цене всегда идут через человека.
2. **Окно отмены** решает спор Марины и Игоря: скорость почти как у автоотправки, но стоп-кран есть.
3. **`decided_by` всегда заполнено.** Через год видно: письмо ушло по решению человека или по правилу. Это ровно то, что нужно Оле.
4. **Цепочка хешей.** Отредактировать запись задним числом нельзя незаметно — `verify_trail()` покажет, где цепочка разорвана.
5. **Отмена тоже событие.** Отсутствие записи — это не доказательство; доказательство — явная запись.

## 📌 Запомнить

- Автономия выдаётся по типам действий, а не целиком: это позволяет расти постепенно.
- Отложенная отправка с окном отмены — компромисс, который обычно и нужен бизнесу.
- Подтверждение должно занимать секунды и допускать пачку, иначе оно превратится в фикцию.
- Гейт, который жмут не глядя, хуже отсутствия гейта: ответственность формально снята, фактически никто не проверил.
- Аудит-трейл хранит текст, основание, версию промпта, результаты проверок и того, кто санкционировал.
- Журнал должен быть append-only с проверяемой целостностью, иначе он не имеет доказательной силы.
