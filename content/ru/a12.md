# Модуль A12. Счёт на $12 000

> **Уровень:** Middle AI · **Время:** ~50 минут · **Формат:** ситуация → теория → практика → квиз

---

## 🏢 Ситуация

Виктор, CFO, пересылает счёт от провайдера моделей с одной строкой: «Это за месяц?»

**$12 480.** В январе было $900.

Вы начинаете разбираться и находите не одну причину, а четыре:

1. Контент-фабрика (A8) делает четыре вызова на статью, а редактор с фактчекером получают **весь текст целиком** каждый раз.
2. В письма стали класть память клиента (A10) — вроде мелочь, но она уходит в каждый вызов.
3. Кто-то поставил самую большую модель везде, включая классификацию входящих, где хватило бы младшей.
4. Одна и та же документация из RAG улетает в контекст на каждом из 3000 писем.

Виктор не против расходов. Он против того, что никто не мог назвать цену заранее: «Скажи мне стоимость одного письма и одной статьи. Дальше я сам посчитаю, сколько мы можем себе позволить».

## 🎯 Ваша задача

1. Научиться считать стоимость единицы работы, а не смотреть на счёт в конце месяца.
2. Снизить её в разы, не потеряв качество, — четырьмя приёмами.
3. Поставить бюджеты так, чтобы такой счёт стал невозможен.

### Роутинг: не всякая задача требует старшей модели

Простое правило: **чем строже контракт на выход, тем меньше нужна модель**. Классификация в закрытый enum (A3), извлечение полей, короткое резюме — это работа для младшей модели. Написание письма, план статьи, разбор инцидента — для старшей.

Как выбирать честно: прогоните обе модели на golden set из A6. Если младшая теряет 1% качества и стоит в пять раз меньше — выбор очевиден. Если теряет 15% — не экономьте.

Полезный паттерн — **эскалация**: младшая модель отвечает, а если её уверенность ниже порога, задача уходит старшей. Дорогие вызовы достаются только сложным случаям.

### Кэширование префикса: главный недооценённый приём

Ваш system-промпт с примерами и куски документации одинаковы на каждом из 3000 вызовов. Провайдеры позволяют закэшировать этот **префикс**: он оплачивается по сниженной ставке при повторных обращениях.

Условие — стабильность начала запроса. Отсюда порядок сборки контекста:

```
[system + примеры + общая документация]   ← стабильно, кэшируется
[память клиента]                          ← меняется по клиенту
[данные конкретного лида]                 ← меняется каждый раз
```

Если поставить меняющееся в начало, кэш не сработает вообще. Это самая частая ошибка в этой теме.

### Что не стоит экономить

- **На проверках.** Фактчекер дешевле одного письма про «интеграцию с 1С».
- **На отказах.** Отказ генерировать — самый дешёвый вызов из возможных.
- **На эвалах.** Прогон golden set стоит копейки против недели работы вслепую.

## 💻 Практика

```python
import os, json, anthropic

client = anthropic.Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])

# Цены за миллион токенов — подставьте актуальные из прайса вашего провайдера
PRICING = {
    "small": {"in": 0.80, "out": 4.00},
    "large": {"in": 3.00, "out": 15.00},
}
MODELS = {"small": "claude-haiku-4-5-20251001", "large": "claude-sonnet-5"}

# Роутинг: строгий контракт на выход → младшая модель
TASK_TIER = {
    "triage": "small",        # классификация в enum (A3)
    "extract_facts": "small", # извлечение полей (A10)
    "summarize": "small",
    "plan_article": "large",  # рассуждение
    "write_email": "large",
    "factcheck": "large",     # цена ошибки высока — не экономим
}

spend = {"in": 0, "out": 0, "cached": 0, "calls": 0}

def call(task, system_blocks, user, tools=None, **kw):
    """system_blocks: [(текст, кэшировать?)] — стабильное идёт первым."""
    tier = TASK_TIER[task]
    system = []
    for text, cacheable in system_blocks:
        block = {"type": "text", "text": text}
        if cacheable:
            block["cache_control"] = {"type": "ephemeral"}   # кэшируем стабильный префикс
        system.append(block)

    resp = client.messages.create(
        model=MODELS[tier], system=system,
        messages=[{"role": "user", "content": user}],
        tools=tools or [], **kw)

    u = resp.usage
    spend["calls"] += 1
    spend["in"] += u.input_tokens * PRICING[tier]["in"] / 1e6
    spend["out"] += u.output_tokens * PRICING[tier]["out"] / 1e6
    spend["cached"] += getattr(u, "cache_read_input_tokens", 0)
    return resp


# --- Эскалация: дорогая модель только для сложных случаев ---
def triage_with_escalation(email_text):
    r = call("triage", [(TRIAGE_SYSTEM, True)], email_text,
             tools=[TRIAGE_TOOL], tool_choice={"type": "tool", "name": "triage"},
             max_tokens=400, temperature=0)
    result = next(b for b in r.content if b.type == "tool_use").input
    if result["confidence"] >= 0.8:
        return result, "small"
    # неуверенно — переспрашиваем старшую модель
    TASK_TIER["triage"] = "large"
    try:
        r = call("triage", [(TRIAGE_SYSTEM, True)], email_text,
                 tools=[TRIAGE_TOOL], tool_choice={"type": "tool", "name": "triage"},
                 max_tokens=400, temperature=0)
        return next(b for b in r.content if b.type == "tool_use").input, "large (эскалация)"
    finally:
        TASK_TIER["triage"] = "small"


# --- Бюджет: жёсткий предохранитель против счёта на $12 000 ---
class Budget:
    def __init__(self, daily_usd):
        self.limit = daily_usd
        self.spent = 0.0
    def check(self, estimated):
        if self.spent + estimated > self.limit:
            raise RuntimeError(f"дневной бюджет исчерпан: {self.spent:.2f} из {self.limit}")
    def add(self, actual):
        self.spent += actual

budget = Budget(daily_usd=40)

def cost_per_unit():
    """Ответ Виктору: стоимость одной единицы работы."""
    return {
        "письмо": round((spend["in"] + spend["out"]) / max(spend["calls"], 1), 4),
        "потрачено_всего": round(spend["in"] + spend["out"], 2),
        "прочитано_из_кэша_токенов": spend["cached"],
    }


# --- Сборка контекста в правильном порядке ---
def build_email(lead, memory, docs):
    return call(
        "write_email",
        system_blocks=[
            (OUTREACH_SYSTEM + "\n\n" + docs, True),      # стабильно → кэш
        ],
        user=(f"ПАМЯТЬ КЛИЕНТА:\n{json.dumps(memory, ensure_ascii=False)}\n\n"
              f"ЛИД:\n{json.dumps(lead, ensure_ascii=False)}"),   # меняется → после кэша
        tools=[DRAFT_TOOL], tool_choice={"type": "tool", "name": "save_draft"},
        max_tokens=800, temperature=0.7)
```

Что даёт каждый приём в нашем случае:

1. **Роутинг.** Разбор 180 входящих в день переехал на младшую модель — минус около 70% на этой задаче без потери качества (проверено на golden set).
2. **Кэш префикса.** Документация и system-промпт перестали оплачиваться 3000 раз в день.
3. **Обрезка контекста.** Редактор в контент-фабрике получает раздел, а не всю статью; память — восемь фактов, а не вся история.
4. **Бюджет.** Дневной лимит превращает «сюрприз в конце месяца» в понятную ошибку сегодня.

## 📌 Запомнить

- Стоимость меряют на единицу работы, а не по счёту в конце месяца.
- Роутинг моделей — первый рычаг: чем строже контракт на выход, тем меньше нужна модель.
- Кэш префикса работает только при стабильном начале запроса: сначала неизменное, потом переменное.
- Эскалация даёт качество старшей модели по цене младшей на большинстве случаев.
- Не экономят на проверках, отказах и эвалах — они дешевле последствий.
- Дневной бюджет — предохранитель: он превращает будущий счёт-сюрприз в сегодняшнюю понятную ошибку.
