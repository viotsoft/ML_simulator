## 🏢 Ситуация

В модуле C4 вы закрыли комплаенс гейтом предусловия. Виктор доволен, но у Кости новая жалоба, и она странная:

> «Агент путается во времени. Пишет клиенту „ваш заказ доставлен вчера“, хотя доставили три недели назад. И наоборот. Раз в десять диалогов.»

Смотрите, откуда агент берёт даты. Инструменты приходят из трёх разных MCP-серверов, каждый писала своя команда в свой год:

```
billing-mcp    → {"paid_at": 1793491200}                    Unix timestamp
orders-mcp     → {"delivered_at": "2026-08-14T09:20:00Z"}   ISO 8601
legacy-crm-mcp → {"contact_date": "14/08/26", "status": 3}  DD/MM/YY + числовой код
```

Три формата даты в одном разговоре. Плюс `status: 3` — что означает «доставлено», но знает об этом только легаси-CRM. Модель разбирает это как умеет, и раз в десять диалогов ошибается.

Костя предлагает описать все форматы в системном промпте. Вы уже знаете из C4, чем заканчиваются вероятностные решения детерминированных задач.

Заодно всплывает второе: тот же гейт возвратов вы зашили прямо в цикл агента поддержки. Теперь такой же лимит нужен research-агенту, который умеет заказывать платные отчёты, и внутреннему тулу для разработчиков. Копировать `if` в три места — плохая идея.

## 🎯 Ваша задача

1. Разобраться, где в жизненном цикле вызова стоят хуки и чем `PostToolUse` отличается от перехвата исходящего вызова.
2. Нормализовать разнородные данные до того, как их увидит модель.
3. Вынести правило «возврат выше лимита → эскалация» из цикла в хук, чтобы оно работало во всех агентах одинаково.

**Перехват исходящего вызова** — до выполнения. Здесь живут политики: заблокировать действие, нарушающее правило, и **перенаправить в альтернативный сценарий**. Каноничный пример гайда: возврат выше порога не выполняется, а уходит в эскалацию на человека.

**`PostToolUse`** — после выполнения, до того, как результат увидит модель. Здесь происходит трансформация: привести разнородные форматы к одному, развернуть числовые коды в понятные значения, обрезать лишнее.

### Нормализация — это не косметика

Проблема Кости — ровно тот пример, который гайд приводит дословно: **Unix timestamps, ISO 8601, числовые коды статусов из разных MCP-инструментов**. Пока каждый сервер отдаёт своё, модель тратит внимание на разбор форматов вместо задачи — и ошибается на границах.

```
До PostToolUse                          После PostToolUse
{"paid_at": 1793491200}                 {"paid_at": "2026-10-01T00:00:00Z"}
{"delivered_at": "2026-08-14T09:20:00Z"} {"delivered_at": "2026-08-14T09:20:00Z"}
{"contact_date": "14/08/26",             {"contact_date": "2026-08-14T00:00:00Z",
 "status": 3}                             "status": "delivered"}
```

Смысл не в красоте, а в том, что после нормализации **все даты сравнимы**, и «доставлено вчера» перестаёт зависеть от того, какой сервер ответил.

### Хук против промпта — второй раз, и это не совпадение

Гайд повторяет ту же мысль, что и в цели 1.4, уже применительно к хукам: **выбирайте хуки вместо принуждения промптом, когда бизнес-правило требует гарантированного соблюдения**. Разница между 1.4 и 1.5 в том, *где* находится механизм: в 1.4 речь про предусловия и порядок шагов, в 1.5 — про сам механизм перехвата в SDK.

Практически это означает: правило, зашитое в цикл конкретного агента, — временное решение. Правило, вынесенное в хук, применяется ко всем агентам, у которых этот хук подключён, и не зависит от того, что написано в их промптах.

| Задача | Механизм |
| --- | --- |
| «Отвечай вежливо и по-русски» | системный промпт |
| «Не возвращай больше 500 без человека» | хук перехвата вызова |
| «Все даты в ISO 8601» | `PostToolUse` |
| «Сначала проверь личность» | предусловие/гейт (C4) |
| «Предпочитай короткие ответы» | системный промпт |

## 💻 Практика

Два хука и один агент. Правила вынесены из цикла: цикл о них ничего не знает.

```python
# pip install anthropic
import os, json, re, anthropic
from datetime import datetime, timezone

client = anthropic.Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])
MODEL = "claude-sonnet-5"
REFUND_LIMIT = 500

STATUS_CODES = {1: "created", 2: "shipped", 3: "delivered", 4: "returned"}

# ---------- хук 1: перехват исходящего вызова (политика) ----------
def before_tool(name: str, args: dict):
    """Возвращает None (разрешить) или строку-причину блокировки с альтернативой."""
    if name == "process_refund" and args.get("amount", 0) > REFUND_LIMIT:
        return (f"BLOCKED by policy: возврат {args['amount']} превышает лимит {REFUND_LIMIT}. "
                "Вызовите escalate_to_human со структурированной сводкой "
                "(customer_id, root_cause, amount, recommended_action).")
    return None

# ---------- хук 2: PostToolUse (нормализация) ----------
def normalize_value(key: str, value):
    if key == "status" and isinstance(value, int):
        return STATUS_CODES.get(value, f"unknown_{value}")
    if isinstance(value, int) and key.endswith(("_at", "_date")) and value > 1_000_000_000:
        return datetime.fromtimestamp(value, tz=timezone.utc).isoformat().replace("+00:00", "Z")
    if isinstance(value, str) and re.fullmatch(r"\d{2}/\d{2}/\d{2}", value):
        d, m, y = value.split("/")
        return f"20{y}-{m}-{d}T00:00:00Z"
    return value

def post_tool_use(name: str, result: dict) -> dict:
    """Приводим разнородные форматы к одному ДО того, как результат увидит модель."""
    if not isinstance(result, dict):
        return result
    out = {k: normalize_value(k, v) for k, v in result.items()}
    changed = {k: (result[k], out[k]) for k in out if out[k] != result[k]}
    if changed:
        print(f"    ↻ нормализовано в {name}: {changed}")
    return out

# ---------- инструменты трёх разных MCP-серверов ----------
TOOLS = [
    {"name": "get_payment", "description": "Платёж по заказу (billing-mcp).",
     "input_schema": {"type": "object", "properties": {"order_id": {"type": "string"}}, "required": ["order_id"]}},
    {"name": "get_order", "description": "Заказ и доставка (orders-mcp).",
     "input_schema": {"type": "object", "properties": {"order_id": {"type": "string"}}, "required": ["order_id"]}},
    {"name": "get_contact", "description": "Последний контакт с клиентом (legacy-crm-mcp).",
     "input_schema": {"type": "object", "properties": {"customer_id": {"type": "string"}}, "required": ["customer_id"]}},
    {"name": "process_refund", "description": "Возврат средств.",
     "input_schema": {"type": "object", "properties": {"customer_id": {"type": "string"}, "amount": {"type": "number"}},
                      "required": ["customer_id", "amount"]}},
    {"name": "escalate_to_human", "description": "Эскалация со структурированной сводкой.",
     "input_schema": {"type": "object", "properties": {
         "customer_id": {"type": "string"}, "root_cause": {"type": "string"},
         "amount": {"type": "number"}, "recommended_action": {"type": "string"}},
         "required": ["customer_id", "root_cause", "recommended_action"]}},
]

def run_tool(name, args):
    return {
        "get_payment": {"paid_at": 1793491200, "amount": 4900, "status": 2},
        "get_order":   {"delivered_at": "2026-08-14T09:20:00Z", "carrier": "CDEK"},
        "get_contact": {"contact_date": "14/08/26", "status": 3, "channel": "email"},
        "process_refund": {"ok": True, "refunded": args.get("amount")},
        "escalate_to_human": {"ok": True, "ticket": "H-1043"},
    }.get(name, {"error": f"unknown_tool:{name}"})

def agent(question: str, max_iterations: int = 12):
    messages = [{"role": "user", "content": question}]
    for _ in range(max_iterations):
        resp = client.messages.create(model=MODEL, max_tokens=1024, tools=TOOLS, messages=messages)
        if resp.stop_reason != "tool_use":
            return "".join(b.text for b in resp.content if b.type == "text")
        messages.append({"role": "assistant", "content": resp.content})
        results = []
        for b in resp.content:
            if b.type != "tool_use":
                continue
            blocked = before_tool(b.name, b.input)                    # хук 1
            if blocked:
                print(f"    ⛔ {b.name}: {blocked}")
                results.append({"type": "tool_result", "tool_use_id": b.id,
                                "content": blocked, "is_error": True})
                continue
            out = post_tool_use(b.name, run_tool(b.name, b.input))     # хук 2
            results.append({"type": "tool_result", "tool_use_id": b.id,
                            "content": json.dumps(out, ensure_ascii=False)})
        messages.append({"role": "user", "content": results})
    return None

if __name__ == "__main__":
    print(agent("Клиент C-88214, заказ 88214: когда его доставили, когда прошёл платёж "
                "и когда мы с ним последний раз связывались? Верни ему 4900 за брак."))
```

**Задание.**

1. Отключите `post_tool_use` и задайте вопрос «сколько дней прошло между платежом и доставкой». Сравните ответы с нормализацией и без — на пяти прогонах.
2. Проверьте перенаправление: сумма 4900 выше лимита 500, агент должен уйти в `escalate_to_human`. Затем сделайте сообщение блокировки просто `"BLOCKED"` и посмотрите, как он вместо эскалации начнёт повторять возврат.
3. Добавьте четвёртый «сервер», отдающий дату строкой `"August 14, 2026"`, и расширьте нормализатор. Обратите внимание: агент менять не пришлось — правило живёт в хуке.

- **Цель 1.5** закрыта: `PostToolUse` для трансформации результатов, перехват исходящего вызова для политик, выбор хука вместо промпта ради гарантий.
- Сценарии: **Customer Support Resolution Agent** (лимит возврата, эскалация), **Developer Productivity with Claude** и **Multi-Agent Research System** (разнородные форматы от разных MCP-серверов).
- Ловушка: вариант «описать все форматы дат в системном промпте, чтобы модель их понимала». Модель справится в большинстве случаев — но это опять вероятностное решение детерминированной задачи.
- Различайте позицию хука по задаче в вопросе: «до того, как модель обработает результат» → `PostToolUse`; «не дать выполнить действие» → перехват вызова.
- Помните про **перенаправление**: правильный ответ обычно не «заблокировать», а «заблокировать и увести в альтернативный сценарий» — эскалацию, другой инструмент, запрос подтверждения.

## 📌 Запомнить

- Хук — это ваш детерминированный код в жизненном цикле инструмента. Две позиции: до выполнения (политика) и после (`PostToolUse`, трансформация).
- `PostToolUse` нормализует разнородные данные — Unix timestamps, ISO 8601, числовые коды — до того, как их увидит модель.
- Перехват исходящего вызова блокирует нарушение политики **и перенаправляет** в альтернативный сценарий, а не просто отказывает.
- Правило в хуке действует одинаково во всех агентах и не зависит от их промптов. Правило в цикле конкретного агента — копипаста, ждущая рассинхрона.
- Промпт остаётся уместным для стиля, тона и предпочтений. Всё, где нужна гарантия, уходит в хуки.
