# ML Career Simulator

Игровой симулятор карьеры ML-инженера: пользователь «устраивается на работу» джуниором в вымышленную компанию **Datacore** и за 20 модулей вырастает до Middle ML Engineer, решая реальные бизнес-кейсы.

## Запуск локально

```bash
npm install
npm start
# → http://localhost:3000
```

- `http://localhost:3000` — лендинг с описанием продукта и тарифами.
- `http://localhost:3000/app.html` — приложение: регистрация, модули, квизы, сертификат.

## Как это устроено

| Агентный трек | `content/<локаль>/a01.md … a20.md`, `agents.json`, `agent-quizzes.json` | Второй курс: 20 кейсов агентной инженерии, Junior → Senior AI Engineer. Поле `status` (`ready`/`soon`) управляет тем, что уже открыто |

## Разделы приложения

- **📚 Модули** — курс: модули 1–20 (Junior → Middle, сертификат) + 21–23 (Advanced-трек по ML System Design, бонус после сертификата).
- **🎤 Собеседования** — тренажёр интервью: вопрос → ответить вслух → открыть эталонный разбор. Junior-трек бесплатный, Middle и System Design — по подписке.
- **🤖 Агенты** — второй трек «Агентная инженерия»: 20 кейсов о том, как строить агентные системы в компании и выводить их на рынок. Входит в ту же подписку; первые два модуля бесплатные.
- **🏛 Claude Architect** — третий трек: подготовка к экзамену CCAR-F. 20 модулей по весам доменов (27/18/20/20/15%) плюс **пробный экзамен**: 60 вопросов за 120 минут, порог 720 по шкале 100–1000, отчёт с процентом правильных по каждому домену и ссылками на модули провалившегося домена. Первые два модуля бесплатные.
- Сертификатов три и они независимы: «Middle-track ML Engineer» за 20 базовых модулей (`CERT_REQUIRED`), «AI Agent Engineer» за 20 агентных (`AGENT_CERT_REQUIRED`) и «CCAR-F Exam Ready» за 20 модулей трека сертификации **и** пробный экзамен от 720 (`CCA_CERT_REQUIRED`, `CCA_PASS_SCALED`). Прогресс всех треков лежит в одной карте `user.progress`, но считается раздельно по наборам id — см. `TRACK_DEFS`, `TRACKS` и `countPassed` в `server.js`.
- Третий сертификат — внутренний: он подтверждает готовность к экзамену Claude Certified Architect, но не является официальной сертификацией Anthropic. Это оговорено на лендинге, в тексте сертификата и в модуле C20.

## Бизнес-модель

- Модули 1–2 и Junior-трек собеседований — **бесплатно** (регистрация без карты).
- Модули 3–23, треки Middle / System Design, агентный трек и трек сертификации — подписка **$20/мес** (кнопка «Оформить подписку»). Три трека по цене одного — основной аргумент лендинга.
- Сертификат «Middle-track ML Engineer» — после прохождения квизов модулей 1–20 (порог 70%).

## Оплата: WayForPay + Stripe

Приложение умеет принимать платежи через **два** шлюза; активный режим выбирается
переменными окружения (см. `.env.example`), приоритет: WayForPay → Stripe → демо.

### WayForPay (для мерчанта из Украины, карты со всего мира)

Stripe и PayPal не работают как платёжные шлюзы для мерчанта из России/Украины —
у WayForPay такого ограничения нет, а принимать он умеет международные карты.

- `WFP_MERCHANT_ACCOUNT` + `WFP_MERCHANT_SECRET` + `WFP_DOMAIN` → кнопка подписки
  открывает **встроенный виджет оплаты** WayForPay прямо на странице (без ухода на
  внешний сайт), с автосписанием раз в месяц (`regularMode: monthly`);
- `/api/wayforpay/webhook` принимает уведомления о каждом платеже (первом и всех
  последующих автосписаниях), проверяет подпись HMAC-MD5 и активирует подписку;
- `WFP_MERCHANT_PASSWORD` — отдельный секрет для отмены подписки через их API
  управления регулярными платежами (кнопка «Подписка» в шапке → `/api/wayforpay/cancel`);
- **без ключей — демо-режим**, подписка включается мгновенно без оплаты.

Реализация проверена: подпись сверена независимым пересчётом, публичный тестовый
аккаунт WayForPay (`test_merch_n1`) подтверждает и открывает виджет с правильными
данными заказа. Подробности, реквизиты песочницы и как получить боевой аккаунт —
в [DEPLOY.md](DEPLOY.md).

### Stripe (если принимаете платежи не из Украины/РФ/СНГ)

- `STRIPE_SECRET_KEY` + `STRIPE_PRICE_ID` → кнопка подписки ведёт на **Stripe Checkout**;
- `/api/stripe/webhook` обрабатывает `checkout.session.completed` (активация),
  `customer.subscription.updated/deleted` (продление/отмена) — задайте `STRIPE_WEBHOOK_SECRET`;
- после возврата с оплаты `/api/checkout/confirm` активирует подписку, не дожидаясь вебхука;
- кнопка «Подписка» в шапке открывает **Stripe Billing Portal** (смена карты, отмена).

Пошаговая настройка обеих платёжек и деплой — в [DEPLOY.md](DEPLOY.md).

## Маркетинг: автопостинг в соцсети

Встроенный SMM-конвейер с веб-панелью **`/admin/marketing`**: генерация EN-контента
из материалов курса (Claude API), карточки и видео с музыкой, автопостинг по
расписанию в Facebook, Instagram, LinkedIn, TikTok, Threads и X, OAuth-подключение
сетей кнопками, utm-атрибуция регистраций до конкретного поста. Движок — в
`marketing/`, подробности — в [MARKETING.md](MARKETING.md).

## Админка: кто зарегистрировался

`/admin` — список всех пользователей (имя, email, дата регистрации, PRO/FREE, прогресс,
сертификат). Защищена HTTP Basic Auth по переменной `ADMIN_PASSWORD` (логин любой, значение —
пароль); без этой переменной раздел выключен целиком (404). Хэши и соли паролей в ответ
API `/api/admin/users` не попадают.

Данные пользователей до сих пор хранятся не в СУБД, а в одном JSON-файле
(`data/users.json` → на хостинге путь из `DATA_DIR`, у нас — постоянный диск Railway).
Годится для MVP; при заметном росте регистраций стоит перейти на SQLite/Postgres —
файл легко читает гонки записи при параллельных запросах.

## Настройки (server.js)

- `FREE_MODULES = 2` — сколько первых модулей базового курса бесплатны. В агентном треке и треке сертификации доступ задаётся флагом `free` у модуля, а не позицией.
- `PASS_SCORE = 0.7` — порог прохождения квиза. Он же служит якорем шкалы пробного экзамена: 70% правильных дают ровно 720 баллов.
- `TRACK_DEFS` — список треков: префикс id, число модулей для сертификата, соль для `certId`. Новый трек добавляется строкой здесь; проверка непересечения id всех треков выполняется на старте.
- `CCA_EXAM_ITEMS = 60`, `CCA_EXAM_MINUTES = 120`, `CCA_EXAM_SCENARIOS = 4`, `CCA_PASS_SCALED = 720` — параметры пробного экзамена; `CCA_DOMAIN_QUOTA` задаёт распределение вопросов по доменам.
- `PORT` — переменная окружения (по умолчанию 3000).

## Пробный экзамен: как устроен

Правильные ответы и таймер живут на сервере. Ответ, отправленный после `endsAt`, отклоняется (409),
а следующее чтение попытки закрывает её автоматически, засчитывая неотвеченное как неверное, —
подмена клиентского таймера ничего не даёт. Ответы схемы `start` и `attempt` не содержат ни
`answers`, ни `explanation`: разбор открывается только через `/api/cca-exam/result/:attemptId`
после сдачи.

Оценка кусочно-линейная с якорем на `PASS_SCORE`: 42 правильных из 60 дают ровно 720, 41 — 705.
Вопросы с множественным выбором засчитываются только при полном совпадении набора.

**Известное ограничение:** банк содержит ровно 60 вопросов — один полный экзамен. Поэтому все
попытки состоят из одних и тех же вопросов, и настойчивый пользователь может выучить ответы
из разбора первой попытки. Для трёх непересекающихся попыток банк нужно довести до 180 вопросов;
формат `cca-exam.json` к этому готов, сборщик уже отбирает по квотам доменов и сценариям.

## Добавление нового модуля

1. Создайте `content/<локаль>/m21.md` (структура: ситуация → задача → теория → практика → разбор) в **обеих** локалях: при отсутствии английского файла отдаётся русский, а вот русского может не оказаться вовсе.
2. Добавьте запись в `content/<локаль>/modules.json` (для агентного трека — `agents.json`, для трека сертификации — `cca.json`).
3. Добавьте вопросы в соответствующий файл квизов под ключом модуля. Порядок вариантов и индексы `answer` обязаны совпадать в обеих локалях — переводится только текст.
4. Перезапустите сервер.

## Добавление нового трека

1. Добавьте строку в `TRACK_DEFS` (`server.js`): ключ, имя поля в `CONTENT`, регулярка префикса id, порог сертификата, соль.
2. Загрузите файлы контента через `readContent(..., [])` рядом с остальными — с фолбэком, чтобы битый новый файл не уронил живой курс.
3. Добавьте объект в `TRACK_UI` и строку в `SECTIONS` (`public/js/app.js`), плюс ключи i18n в оба словаря.
4. Роуты копируются с агентных: порядок проверок — 409 «скоро» **до** 402 paywall.

## Что стоит сделать перед реальным продом

- Заменить JSON-хранилище на PostgreSQL/SQLite.
- Stripe для подписок (см. выше), email-подтверждение регистрации.
- HTTPS + флаг `Secure` у cookie, rate limiting на auth-эндпоинты.
- Хостинг: любой Node-хостинг (Railway, Render, Fly.io) — приложение без нативных зависимостей.
